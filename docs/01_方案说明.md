# 01 方案说明

## 一、为什么选这个实验

### 1.1 简历项目的价值排序（考研视角）

导师看简历上的项目，实际在看三件事：**做了什么 → 为什么这么做 → 结果如何证明**。

| 价值等级 | 典型项目 | 问题 |
|---------|---------|------|
| 低 | 跑个 MNIST、调个 sklearn | 太简单，人人都会，无法体现能力 |
| 中 | 图像分类微调、目标检测微调 | 有完整工程链路，能讲清方法论 |
| 高 | LoRA 大模型微调、扩散模型、推理优化 | 最有含金量，但门槛高、周期长 |

**策略：不要一步到位做最难的那个。** 正确路径是沿**一个方向**由浅入深，让每个项目都能接上前一个的基础，形成连贯的技术叙事。

### 1.2 方案 A（视觉线）的路线

~~~
① 迁移学习图像分类（CIFAR-10 / ResNet-18）   ← 你在这里
        ↓  学会：训练管线、数据增强、优化器、迁移学习
③ 目标检测微调（YOLO）
        ↓  学会：检测头、锚框/无锚框、mAP、NMS、自定义数据集
⑤ 扩散模型（Stable Diffusion 类）
        ↓  学会：噪声预测、去噪过程、采样策略
~~~

### 1.3 第一步的定位

第一步不是「做出最牛的结果」，而是**建立一条干净、完整、可讲清的训练-评估管线**。这条管线后面做检测、做生成都会复用。同时它是一个**对照实验**，天然具备「有变量、有对照、有结论」的科学结构——这正是老师最想看到的。

## 二、实验设计

### 2.1 实验问题

> 在同样的数据与网络结构下，使用 ImageNet 预训练权重微调，相比随机初始化从头训练，能在**收敛速度**和**最终精度**上带来多大提升？

### 2.2 控制变量

| 变量 | 设置 | 说明 |
|------|------|------|
| 数据集 | CIFAR-10 | 5 个训练 batch + 1 个测试 batch，共 60000 张 32×32 彩色图 |
| 骨干网络 | ResNet-18 | 两组实验完全一致，仅初始化方式不同 |
| 训练集 | 50000 张（数据集原生） | 统一使用 |
| 测试集 | 10000 张 | 统一使用，只在训练结束后评估 |
| 优化器 | SGD + momentum=0.9, weight_decay=5e-4 | 一致 |
| 学习率调度 | CosineAnnealingLR, T_max=epochs | 一致 |
| 训练轮数 | 10 epochs | 一致 |
| 随机种子 | 42 | 一致，保证可复现 |
| **唯一变量** | **权重初始化** | 随机初始化 vs ImageNet 预训练 |

### 2.3 差异点说明

- 从头训练的学习率设为 lr × 2（2e-3），迁移学习用 lr（1e-3）。这是迁移学习的**通用实践**：预训练权重已经是好解，步子太大容易破坏，故用更小学习率微调。这一点在面试中要主动说明。
- 迁移学习只替换最后一层全连接：把 ImageNet 的 1000 类分类头换成 CIFAR-10 的 10 类头（m.fc = nn.Linear(m.fc.in_features, 10)）。

### 2.4 数据增强

- 训练集：RandomCrop(32, padding=4) + RandomHorizontalFlip
- 测试集：不做增强，保持原始分布
- 标准化使用 CIFAR-10 官方统计量：均值 (0.4914, 0.4822, 0.4465)，标准差 (0.2470, 0.2435, 0.2616)

## 三、预期与假设

动手前先立假设（这是科研训练的关键一步）：

1. 迁移学习的**首个 epoch** 精度就会明显高于从头训练 —— 因为预训练特征已具备通用纹理/边缘判别力。
2. 最终精度迁移学习也更高 —— 因为省下的训练预算可以花在精细化分类边界上。
3. 迁移学习收敛更快 —— 用更少 epoch 达到从头训练更多 epoch 的水平。

**实测结果全部验证了这三个假设**（见 04_实验报告.md）。
