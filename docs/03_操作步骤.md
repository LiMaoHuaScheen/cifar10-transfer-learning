# 03 操作步骤

> 从零复现整个实验的完整流程。假设已完成 02_环境搭建.md。

## 第 0 步：进入项目目录

~~~powershell
cd cifar10-transfer-learning
~~~

## 第 1 步：确认数据就绪

~~~powershell
dir .\data\cifar-10-batches-py
~~~

应看到 6 个数据文件：batches.meta、data_batch_1..5、test_batch。
如果缺文件，回到 02_环境搭建.md 第四节重新下载。

## 第 2 步：跑训练实验

~~~powershell
& python train_cifar.py --data-root data --epochs 10 --device cuda
~~~

脚本会**自动依次跑两组实验**：先从头训练，再迁移学习微调。

### 2.1 命令行参数

| 参数 | 默认 | 说明 |
|------|------|------|
| --data-root | data | 数据集根目录，需包含 cifar-10-batches-py |
| --epochs | 10 | 训练轮数 |
| --batch-size | 64 | 批大小 |
| --lr | 1e-3 | 迁移学习的学习率；从头训练自动 ×2 |
| --device | cuda | cuda / cpu |
| --workers | 2 | DataLoader 线程数 |
| --seed | 42 | 随机种子，保证可复现 |

### 2.2 运行时长参考（RTX 5060 Laptop）

| 实验 | 每轮耗时 | 10 轮总耗时 |
|------|---------|------------|
| 从头训练 | 约 175 s/epoch | 约 29 分钟 |
| 迁移学习 | 约 39 s/epoch | 约 6.5 分钟 |

从头训练第一轮更慢，因为需要下载 ImageNet 预训练权重以外的缓存文件；迁移学习权重已缓存时很快。

## 第 3 步：检查输出

~~~powershell
dir .\output
~~~

应生成 3 个文件：

| 文件 | 内容 |
|------|------|
| result_summary.json | 两组实验的逐轮 train/test 准确率 + 最佳值 |
| learning_curve.png | 学习曲线（需运行下一步脚本生成） |
| accuracy_bar.png | 准确率对比柱状图（同上） |

## 第 4 步：生成图表

~~~powershell
& python plot_curve.py
~~~

脚本读取 output/result_summary.json，生成 learning_curve.png 与 accuracy_bar.png。

> 注意：图表标签必须用英文，否则 matplotlib 的 DejaVu Sans 字体缺 CJK 字形，中文会变方框。

## 第 5 步（可选）：调整实验

常见改法：

| 想做什么 | 怎么改 |
|---------|--------|
| 训练更久 | --epochs 20 |
| 换骨干网络 | 改 train_cifar.py 中 build_model()，把 resnet18 换成 resnet34/resnet50 |
| 加更强增强 | 在 build_loaders() 的训练 transform 里加 transforms.RandomRotation(15) |
| 分层学习率 | 把优化器参数改成两组 param_groups（backbone 小 lr，fc 大 lr） |
| 换数据集 | 换成 CIFAR-100（注意 num_classes 改成 100，且标准化均值方差要换） |

把 output/ 下三张产物 + train_cifar.py 一起作为项目成果归档。
写简历时直接引用其中的量化数字（71.48% / 82.04% / +10.56pp）。
