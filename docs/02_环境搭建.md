## 二、Python 解释器

预装：numpy 2.3.5、opencv-python-headless 5.1.0.95、pillow 12.3.0。没有 torch。

~~~

## 三、安装 PyTorch（最耗时的一步）

**坑 1：官方源极慢。** 直连 PyPI / pytorch.org 实测只有 1.5~1.8MB/s 甚至更慢，大文件基本不可用。
**解决：全程用国内镜像。**

~~~powershell
# 1) 先下载 torch wheel 到本地（阿里云镜像，实测 2.56GB / 29 分钟 ≈ 1.49MB/s）
curl -L -o cifar10-transfer-learning\wheels\torch.whl "https://mirrors.aliyun.com/pytorch-wheels/cu128/torch-2.11.0%2Bcu128-cp312-cp312-win_amd64.whl"
~~~

~~~powershell
# 2) 用本地 wheel 安装，依赖从阿里云 PyPI 镜像拉取
& python -m pip install .\torch.whl torchvision --index-url https://mirrors.aliyun.com/pypi/simple/
~~~

**坑 2：--no-index --find-links 安装会失败。** 报错 "Could not find a version that satisfies the requirement filelock"，因为依赖项不在本地。
**解决：不要加 --no-index**，正确写法是「本地 wheel + --index-url 阿里云」，让 pip 自己找依赖。

~~~powershell
# 3) 验证
& python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
# 期望输出：2.11.0+cu128 True
~~~

## 四、安装 matplotlib（绘图用）

~~~powershell
& python -m pip install matplotlib --index-url https://mirrors.aliyun.com/pypi/simple/
~~~

**坑 3：matplotlib 缺中文字体。** 默认 DejaVu Sans 不含 CJK 字形，图上中文会变方框，并刷屏
"UserWarning: Glyph 20174 (\N{CJK UNIFIED IDEOGRAPH-4ECE}) missing from font(s) DejaVu Sans."
**解决：图表标签全部用英文**（最终方案），比硬装字体更省事。

## 五、下载 CIFAR-10 数据集

**坑 4：官方源几乎不可用。** torchvision 默认的 Toronto 镜像实测约 9KB/s，下载 170MB 要几个小时。
**解决：用百度云数据镜像，实测约 1.03MB/s。**

~~~powershell
curl -L -o cifar10-transfer-learning\data\cifar-10-python.tar.gz "https://dataset.bj.bcebos.com/cifar/cifar-10-python.tar.gz"
~~~

解压后目录：

~~~
data/
├── cifar-10-python.tar.gz
└── cifar-10-batches-py/
    ├── batches.meta
    ├── data_batch_1 .. data_batch_5   （每个 29.6 MB）
    └── test_batch                      （29.6 MB）
~~~

**坑 5（最重要）：不要用两个进程同时写同一个压缩包。** 曾有后台残留的下载任务与新下载并发写同一路径，导致 gzip 损坏，解压时报
"Truncated tar archive detected" 和 "Damaged tar archive (bad header checksum)"。
**解决：先确认没有残留下载进程，再重新干净下载一次。** 判断损坏与否最快：先 tar -tzf 试一下。

## 六、预训练权重

ResNet-18 的 ImageNet 预训练权重由 torchvision 自动下载，文件名 resnet18-f37072fd.pth。首次运行会自动拉取，之后走缓存。

## 七、清理建议

wheels/ 目录约 2.6GB，是安装用的 torch wheel 安装包，装完即可删除，不影响已装环境：

~~~powershell
Remove-Item cifar10-transfer-learning\wheels -Recurse -Force
~~~
