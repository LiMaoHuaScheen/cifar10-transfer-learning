# 06 代码说明

## train_cifar.py 结构总览

~~~
parse_args()        命令行参数
set_seed()          固定随机种子
build_loaders()     数据加载 + 预处理管线
build_model()       构建 ResNet-18（两种初始化）
train_one_epoch()   单轮训练
evaluate()          测试集评估
run_experiment()    单次实验的完整循环
main()              编排两组实验 + 保存结果
~~~

## 逐段讲解

### 1. build_loaders()：数据管线

~~~python
tr = transforms.Compose([
    transforms.RandomCrop(32, padding=4), transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize((0.4914,0.4822,0.4465),(0.2470,0.2435,0.2616))])
~~~

- RandomCrop 先 pad 4 像素（变成 40×40）再随机裁回 32×32，等价于随机平移。
- ToTensor 把 HWC uint8 张量转成 CHW float，并归一化到 [0,1]。
- Normalize 用 CIFAR-10 官方统计量做标准化，让各通道均值为 0、方差为 1，训练更稳。

~~~python
train_ds = datasets.CIFAR10(root=root, train=True, download=False, transform=tr)
~~~

- download=False：数据已就位，不从网上拉取（避免触发那个 9KB/s 的慢速镜像）。
- 训练集 shuffle=True，测试集 shuffle=False。

### 2. build_model()：两种初始化

~~~python
if mode == "scratch":
    return models.resnet18(weights=None, num_classes=num_classes), ...
else:
    m = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)
    m.fc = nn.Linear(m.fc.in_features, num_classes)
~~~

- weights=None → 随机初始化（从头训练）。
- weights=ResNet18_Weights.IMAGENET1K_V1 → 加载 ImageNet 预训练权重。
- 关键点：先加载预训练权重，再替换 fc。如果先替换再加载，加载会报错（shape 不匹配）。
- m.fc.in_features 在 ResNet-18 上是 512。

### 3. run_experiment()：核心循环

~~~python
lr = args.lr*2 if mode=="scratch" else args.lr
optimizer = optim.SGD(model.parameters(), lr=lr, momentum=0.9, weight_decay=5e-4)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=args.epochs)
~~~

- 从头训练 2e-3，迁移学习 1e-3（迁移学习实践：小步微调）。
- scheduler.step() 在每轮末尾调用，学习率按余弦曲线下降。

~~~python
if tea > best:
    best = tea; best_state = copy.deepcopy(model.state_dict())
~~~

- 记录最佳测试准确率对应的权重。训练结束后 load_state_dict 回滚到最佳状态再评估。
- 这是标准的「按验证表现选模型」做法，避免用可能已过拟合的最后一轮。

### 4. train_one_epoch()：单轮训练

~~~python
for images, labels in loader:
    images, labels = images.to(device), labels.to(device)
    optimizer.zero_grad(); out = model(images); loss = criterion(out, labels)
    loss.backward(); optimizer.step()
~~~

这是最经典的 PyTorch 训练五步：零梯度 → 前向 → 算损失 → 反向 → 更新参数。
注意先 optimizer.zero_grad() 再反向，因为 PyTorch 默认累加梯度。

### 5. main()：编排

~~~python
results["scratch"] = run_experiment("scratch", ...)
results["finetune"] = run_experiment("finetune", ...)
~~~

两组实验顺序执行，共享同一个 train_loader / test_loader（数据与增强完全一致，这是控制变量的关键）。
最后把逐轮准确率写进 output/result_summary.json，供 plot_curve.py 消费。

## 扩展改造指南

### 加数据增强消融

在 build_loaders 里加一个开关：

~~~python
tr = transforms.Compose([
    transforms.RandomCrop(32, padding=4),
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(15),     # 新增
    transforms.ColorJitter(0.2, 0.2),   # 新增
    transforms.ToTensor(),
    transforms.Normalize(mean, std)])
~~~

跑两组（增强/无增强），比较 test 准确率差，就能量化增强本身的贡献。

### 加分层学习率（Discriminative LR）

~~~python
backbone_params = [p for n, p in m.named_parameters() if not n.startswith("fc.")]
fc_params = m.fc.parameters()
optimizer = optim.SGD([
    {"params": backbone_params, "lr": 1e-4},
    {"params": fc_params, "lr": 1e-2},
], momentum=0.9, weight_decay=5e-4)
~~~

backbone 用很小 lr 保护预训练特征，fc 用大 lr 快速适配新类别。通常比统一 lr 更好。

### 换 ResNet-50

~~~python
return models.resnet50(weights=None, num_classes=num_classes)
~~~

参数量从 3.17M 涨到 25.6M，8GB 显存完全够，batch 可保持 64。
预期：从头训练会明显变好（更深的网络拟合能力更强），迁移学习的优势可能缩小但依然存在。

### 换 CIFAR-100

- num_classes 改 100
- 标准化均值方差要换成 CIFAR-100 的统计量
- 类别数增多后分类更困难，是观察「预训练特征在细粒度任务上价值」的好场景
